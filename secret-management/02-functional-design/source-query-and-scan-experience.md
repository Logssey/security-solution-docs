# 조회와 검사 실행 화면

## 기본 화면

시크릿 화면은 현재 사용자가 열람할 수 있는 연결·키·발견 위치·대응을 통합 조회한다. 기본 읽기 선택은 `origin=ALL`이며 PRODUCTION·TEST·UNCLASSIFIED를 포함한다. 자료 모드 선택, 시험 배지, 시험 출처 복귀 링크, 운영·시험 분류 입력은 일반 화면에서 제공하지 않는다. 저장된 분류와 합성 판정은 감사·검증 안전성의 내부 근거로 관리한다.

고유 키는 credentialSetId, 발견 위치는 occurrenceId, 대응은 caseId 단위로 집계한다. 같은 키의 여러 내부 분류를 조회해도 키는 한 번 집계하고 각 대응 건과 위치의 판단 근거는 해당 객체에 결합한다. 유효성·심각도·보관 적정성은 실제 확인한 근거와 시각을 표시한다.

원천은 사용자에게 `발견 플랫폼`, 환경은 `자원 환경`, 발급자는 `키 발급 서비스`로 표현한다. 키 상세에는 저장소·파일·페이지·리소스와 해당 위치의 환경을 보여준다. 내부 자료 분류를 자원 환경으로 표시하지 않는다.

## 조회 동선

| 화면 | 기본 조작 | 세부 조건 |
|---|---|---|
| 현황 | 확인 필요·대응 중·재검사 대기 선택, 새로고침, 스캔 요청 | 원천·환경 선택은 상세 목록에서 제공 |
| 키·발견 위치 | 검색, 필터, CSV 내보내기 | 플랫폼, 자원 환경, 키 발급 서비스·종류, 구성, 검증, 위험도·업무 |
| 대응 관리 | 검색, 내 담당 업무, 필터 | 단계, 담당자·팀, 위험도·유효성 |
| 확인 필요 목록 | 검색, 필터 | 업무 종류, 플랫폼·환경, 담당 범위 |
| 연결 관리 | 연결 선택, 연결 테스트, 스캔 요청 | 연결 상태 |
| 스캔 이력 | 최근 실행, 필터 | 실행 기간·유형·결과, 연결·플랫폼 |
| 상세 | 위치·근거·담당 작업과 다음 행동 | 객체 정보는 정적인 사실로 표시 |

세부 조건은 기본 접힌 공통 필터 영역에서 편집한다. 현재 적용한 조건은 영역 밖의 짧은 칩과 적용 개수로 표시하며 개별 해제와 전체 초기화를 지원한다. 검색은 제출 시 서버에서 실행하고 허용된 표시 정보 전체에 적용한 후 집계·페이지·CSV를 생성한다. 현재 페이지에서 전체 검색 결과를 추정하지 않는다.

검색 입력은 길이·제어 문자·자격 증명 유사 패턴을 검사한다. 자격 증명 원문으로 보이는 값은 URL·조회 요청·조건 칩에 반영하기 전에 고정 안내로 거절하고 서버에서도 같은 검사를 수행한다. 마스킹된 키 표시와 허용된 위치 정보는 검색할 수 있다. 필터 편집을 닫거나 취소하면 미적용 조건을 버리며, 검색 제출에는 현재 적용된 조건만 함께 사용한다.

조건 변경은 페이지와 조회 스냅샷을 초기화한다. 현황 카드·차트에서 목록으로 이동하면 해당 업무·위험도와 같은 스냅샷을 전달한다. 사이드바의 기본 진입은 페이지별 조건을 초기화한다. 상세의 목록 복귀와 브라우저 뒤로 가기는 검색·조건·페이지·선택 위치를 복원한다.

일반 목록의 이전 PRODUCTION·TEST 선택 URL은 ALL 조회로 정규화하고 이전 분류의 스냅샷을 재사용하지 않는다. 기존 외부 API의 명시적 분류 조회는 호환 계약으로 지원한다. 객체의 명령·감사 참조는 서버에서 확인한 실제 분류·revision을 사용하며 ALL은 읽기 선택으로만 허용한다.

## 현황과 확인 업무

강조 카드는 흰 배경과 동일한 두께의 전체 테두리로 구성한다. 상단·좌측의 두꺼운 장식선은 사용하지 않는다. 양수인 업무 수에 상태별 색상을 적용하고 0·미집계·권한 제한을 구별한다. 카드를 선택하면 동일한 업무 목록 영역을 바꾸고 URL에 선택 업무를 기록한다.

확인 필요는 검토 대상과 대응 생성 대상의 occurrenceId 합집합이다. 자격증명 여부 확인 경고는 실제 허용된 경고·위치 관계로 연결한다. 경고 건수와 위치 수를 단순 합산하지 않는다. 합성 판정·실제 자격증명 확인·인증 유효성은 각각의 근거를 보존한다.

최근 검사 상태는 플랫폼별 대상 수, 검사 성공 수, 최근 시도와 실제 실행 링크를 짧게 제공한다. 누락·지연은 원인과 복구 목록으로 연결한다. 연결 없음, 대상 없음, 현재 대상 미검사, 검색·필터 결과 없음, 조회 오류는 각각의 안내와 행동을 제공한다.

대응 위험도는 하나의 카드에 표시하고 유효성 교차표는 기본 접힌 상세로 제공한다. 위험도 행과 교차표의 양수 건수는 같은 집계 기준의 대응 목록으로 연결한다. 집계 대상이 없을 때는 확인 필요 목록으로 안내한다.

## 연결 관리의 검사 진행 패널

데스크톱에서는 연결 목록 옆의 단일 패널에 선택한 실행을 표시한다. 다른 연결·실행을 선택하면 같은 패널의 내용을 교체한다. 모바일에서는 단일 열로 제공하고 연결 목록으로 복귀할 수 있게 한다. 선택 runId는 URL에 보존한다. 연결 테스트와 스캔 요청은 별도 행동이다.

사용자가 선택한 연결과 검사 대상 수를 확인하고 스캔을 요청하면 기존 비동기 등록 API의 runId를 열어 진행을 조회한다. 이중 제출은 idempotencyKey와 서버의 현재 활성 작업 제약으로 방지한다. 등록 대기와 워커 실행을 구별하고 수동 요청은 정기 6시간 예약을 변경하지 않는다.

| 단계 | 표시 근거 |
|---|---|
| 요청·작업 대기 | 요청 시각, 실제 선점·시작 시각, 다음 재시도 시각 |
| 원천 수집 | 승인 대상 읽기의 실제 단계 상태·처리량·요청 결과 |
| 탐지·정규화 | 실제 탐지 도구 실행·정규화·발견 결과 저장 관측 |
| 유효성 확인 | 실제 인증 시도, 미지원·설정·구성·표본에 따른 생략 |
| 실행 결과 | 완료된 트랜잭션의 실행 상태와 결과 요약 |

수집·탐지·검증은 파일·블록 단위로 겹쳐 실행할 수 있으므로 여러 단계의 동시 진행을 허용한다. 워커 상태와 실행 이벤트에 따라 박스 색과 아이콘을 갱신한다. 경과 시간만으로 단계 완료나 처리율을 생성하지 않는다. 분모가 관측된 경우에만 처리 비율을 표시하고 단위는 대상·파일·키 후보·시도 횟수로 구별한다.

대기는 회색, 진행 중은 옅은 파랑과 진행 아이콘, 완료는 체크, 부분 실패는 주황, 실패는 붉은 상태를 사용한다. 진행 아이콘에만 느린 움직임을 적용하고 reduced-motion 환경에서는 정적인 상태 아이콘을 제공한다. 색과 함께 상태 문구를 표시한다. 생략은 별도 상태와 실제 사유로 표시한다.

단계를 누르면 같은 패널에 터미널 형태의 읽기 전용 실행 내역을 제공한다. 키보드로 단계를 선택하고 내역 제목으로 이동할 수 있다. 내역의 스크롤은 패널 안에서 관리하고 새 이벤트가 도착해도 사용자가 읽던 위치를 강제로 이동하지 않는다. 최신 내역 이동을 별도로 제공한다.

## 실행 내역과 갱신

내역은 시각, 실행 시도, 단계, 실제 operation, 결과, 관측된 HTTP 코드·처리량·소요 시간과 안전한 사유를 사용한다. API·도구 명령 표현은 서버의 등록된 operation 템플릿에서 생성한다. 실제 관측되지 않은 명령·HTTP 응답·stdout은 만들지 않는다. SDK가 HTTP 코드를 제공하지 않으면 코드 미기록으로 표시한다.

토큰·인증 헤더·비밀 인수·원천 본문·공급자 응답 원문·예외 메시지는 실행 내역에 저장하지 않는다. API 응답은 허용된 구조 필드로 정리하고 터미널 텍스트는 일반 텍스트로 렌더링한다. 사용자가 명령이나 외부 URL을 입력해 실행하는 기능은 제공하지 않는다.

진행 중이고 화면이 보일 때 2.5초 간격으로 상태를 조회한다. 이벤트는 단조 증가 ID cursor로 추가 수신하고 중복 제거한다. 한 페이지가 가득 차면 다음 페이지를 순서대로 읽으며 한 번의 갱신에서 최대 20페이지를 처리한다. 완료 상태에서도 남은 이벤트를 수신한 뒤 정기 조회를 종료한다. 화면 전환·비표시·접근 거부 시 자동 조회를 종료하거나 일시 정지한다.

네트워크 오류 때 마지막 확인 시각과 재조회 행동을 표시한다. 조회 오류를 실행 실패로 바꾸지 않는다. 재시도 시도 번호와 과거 이벤트를 함께 보존하되 이전 시도의 성공을 현재 단계의 성공으로 표시하지 않는다.

기존 실행의 상세 이벤트가 없으면 기존 단계 원장과 결과를 표시하고 `상세 실행 내역이 기록되지 않았어요`로 안내한다. 보존 기한 만료·일부 내역 생략·현재 이벤트 없음은 서로 구별한다. 종료 후 발견 결과, 실패 대상, 실행 이력으로 연결한다.

## 동작 수용 기준

- 전체 조회의 카드·미리보기·목록·내보내기는 같은 권한과 조회 기준으로 일치한다.
- 혼합 분류의 같은 키는 한 번 집계하며 실제 대응·위치·보관·폐기 근거를 임의로 합치지 않는다.
- 미분류 자료도 일반 확인·보관 정책·대응 흐름에서 다음 행동이 가능하다.
- 목록 첫 진입은 선택칸을 반복 노출하지 않으며 적용 조건은 언제든 확인·해제할 수 있다.
- 공개 제품 화면에 운영·시험 자료 선택, 시험 배지와 시험 전환 문구가 없다.
- 진행 단계·명령·응답·처리율은 실제 저장된 관측에 대응한다.
- 부분 실패·검증 생략·재시도·이벤트 제한·권한 회수·연결 오류·재접속을 실제 상태로 표시한다.
- 데스크톱·모바일에서 단일 실행 패널, 키보드 초점, 내부 스크롤과 reduced-motion이 동작한다.
