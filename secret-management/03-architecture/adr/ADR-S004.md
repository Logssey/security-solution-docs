# ADR-S004 — 외부 조치 지원과 키 변경 제외

- 상태: **Accepted**
- 결정일: 2026-10-09
- 기준: [PRD](../../01-requirements/PRD.md), FR-12부터 FR-17, SEC-05·SEC-08

## 배경

비정상 노출의 해결에는 키 폐기·교체·재발급·권한 축소·사용 이력 확인이 필요할 수 있다. 변경은 업무 서비스에 영향을 줄 수 있으므로 제품의 탐지·검증 권한과 외부 변경 실행 권한을 분리한다.

## 결정

키 교체·폐기·재발급·권한 변경은 담당자가 외부 시스템에서 수행한다. 제품은 기본 가이드·체크리스트·담당자 지정·위치별 외부 조치 기록·재검사·해결 증거를 제공한다. 제품의 연결 계정에는 키 변경 권한을 부여하지 않는다. 화면의 교체·이관 관련 행동은 안내와 기록을 열며 외부 변경 API를 호출하지 않는다.

검토·체크리스트 완료는 해결 증거가 아니다. 조치 기록에 수행자·시각·변경 내용·근거를 남기고 위치의 미발견·키 수명주기·검사 커버리지를 별개로 확인한다. 확인된 권한·자산·경로와 추정 관계도 구별한다.

## 가이드 보조

대응 업무는 AI 없이 동작한다. 기본 가이드는 정책 버전을 고정하고 선택형 AI의 장애·제한·비활성에서도 반환한다. AI는 제한된 enum에 근거한 설명 보조이며 발견 원문·원천 전체·자유 메모를 전송하지 않는다. 노출·유효성·심각도 판정, 자동 상태 전환·외부 조치 명령에 사용하지 않는다.

외부 공급자는 전송 범위·보관 정책·활성화 승인을 충족해야 하며 어댑터로 분리한다. 공급자 교체는 외부 변경 제외 경계나 대응 명령 계약을 바꾸지 않는다. 세부사항은 [ADR-S009](ADR-S009.md)를 따른다.

## 결과

수집·탐지·검증·재검사·가이드의 어떤 경로도 키 변경 API를 호출하지 않아야 한다. 해결·예외의 증거와 승인 권한은 [대응 정책](../../02-functional-design/response-policy.md)과 [API 계약](../api-contract.md)에 정의한다.
