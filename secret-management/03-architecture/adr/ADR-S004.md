# ADR-S004 — 수동 대응 지원과 선택 기능

- 상태: **Accepted — 수동 대응 지원, 외부 키 변경 실행 제외**
- 결정일: 2026-10-09
- 기준: [PRD v0.4](../../01-requirements/PRD.md), FR-12부터 FR-17, SEC-05, SEC-08

## 이슈

유효한 키의 비정상 노출에는 폐기, 교체, 권한 축소, 사용 이력 확인 등이 필요할 수 있다. 이 제품은 담당자의 판단과 수행을 지원하며 외부 자격 증명이나 권한을 직접 변경하는 실행 주체가 되지 않는다.

## 최종 결정

교체, 폐기, 재발급, 권한 변경을 제품에서 직접 실행하지 않는다. 대응 가이드, 체크리스트, 담당자 지정, 외부에서 수행한 조치의 기록과 재검증 요청을 제공한다. 검토 완료나 체크리스트 체크만으로 해결 처리하지 않는다. 키 변경 권한을 제품 연결 계정에 부여하지 않는다.

## 선택 기능

- 공격 경로: 연결마다 확인한 근거와 시점을 확보할 수 있을 때 추가한다. 추정 경로와 확인된 권한을 구별한다. 실제 악용 여부는 별도 증거가 필요하다.
- AI 요약: 비밀 제거 데이터 범위, 외부 전송, 보관 정책 결정 후 검토한다. 탐지, 유효성 판정, 자동 조치에는 사용하지 않는다.

### AI 가이드 보조의 구현 경계

스프린트의 AI API 연결은 대응 설명과 가이드 초안 생성의 보조 기능이다. 담당자 지정, 검토, 외부 조치 기록, 체크리스트, 재검증과 해결 조건은 AI API 호출 없이도 동작한다. AI 장애 시 버전이 고정된 기본 가이드를 사용하고 저장이나 검사 요청을 막지 않는다.

초기 시험 공급자·모델과 외부 전송 범위는 [ADR-S009](ADR-S009.md)에서 정한다. 다른 보안 기능을 포함한 예상 사용량·비용과 인프라 준비 후 Claude API 연결을 검토한다. 무료·유료 여부와 관계없이 비밀 제거, 전송 범위와 외부 보관 정책을 확인한 뒤 연결하며 초기에는 합성 표본으로 시험한다. 발견한 원문이나 원천 콘텐츠 전체를 프롬프트에 넣지 않고, AI 출력을 유효성·심각도 판정이나 키 변경 명령으로 사용하지 않는다. AI 보조의 도입 계획은 외부 키 변경 제외 결정을 바꾸지 않는다.

## 영향, 검증

화면의 이관, 교체 동작은 절차 안내와 외부 수행 기록을 여는 기능이다. 재검증을 포함한 어떤 제품 동작도 키 변경 API를 호출하지 않는지 확인한다. 조치 기록에는 수행자, 시각, 변경 내용과 근거를 남긴다. 해결과 예외의 증거와 권한은 [대응 정책](../../02-functional-design/response-policy.md)과 [API 계약](../api-contract.md)을 따른다.
