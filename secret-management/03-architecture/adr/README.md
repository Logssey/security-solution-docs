# 아키텍처 결정 기록

채택한 기술 결정과 근거를 기록한다. 제품 동작은 [기능 설계](../../02-functional-design/README.md), 구성과 계약은 [아키텍처](../README.md)를 따른다. 개발 일정·실험 원문·구현 진행률은 이 목록에 포함하지 않는다.

공통 기술 기반과 세션 인증은 [대시보드 설계](https://github.com/Logssey/dashboard-design-docs/blob/main/03-architecture/README.md)를 따른다. Secret 원문 보호와 도메인 실행·저장 경계는 아래 결정을 적용한다. DB의 물리 배포 위치는 환경별 배포 설정이며 API·워커 분리와 원문 접근 경계를 바꾸지 않는다.

모든 문서의 상태는 Accepted다. 연결별 엔드포인트·호출 한도·클러스터 호환 버전·배치 위치는 환경 설정으로 고정하며 미승인 상태에서 능동 실행하지 않는다. 계약을 변경할 때는 결정과 근거를 함께 갱신한다.
