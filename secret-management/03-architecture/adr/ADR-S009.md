# ADR-S009 — 스프린트 2 AI 대응 가이드 시험

- 상태: **Accepted — 선택적 시험 연동**
- 결정일: 2026-10-19
- 기준: [ADR-S004](ADR-S004.md), [원문 비보관 정책](ADR-S005.md), [대응 정책](../../02-functional-design/response-policy.md)

## 문제

대응 담당자에게 키 유형별 조치 순서를 설명할 수 있어야 한다. 외부 AI API는 장애, 사용량 제한, 데이터 보관 정책에 영향을 받으므로 대응 건의 검토·조치·재검증·해결을 AI 호출에 의존시키지 않는다.

## 결정

초기 시험은 [GroqCloud Free](https://console.groq.com/docs/rate-limits)의 `openai/gpt-oss-20b`와 [구조화 JSON 응답](https://console.groq.com/docs/structured-outputs)을 사용한다. 공급자 호출은 별도 어댑터에 두고 `GROQ_API_KEY`와 명시적 활성화 설정이 모두 있을 때만 실행한다. 키가 없거나 호출·검증이 실패하면 버전이 고정된 기본 가이드를 돌려주며 대응 업무를 막지 않는다. 다른 보안 기능의 사용량과 비용을 산정한 뒤 Claude API로 교체할 수 있도록 공급자와 화면 응답 계약을 분리한다.

외부 요청에는 서버가 허용 목록에서 만든 발급자·키 유형·구성 상태·검증 상태·대응 단계 등의 **제한된 enum만** 담는다. 키 원문, 마스킹된 키 끝자리, 지문, 저장소·계정·경로·원천 참조, 사용자 자유 메모, 도구 원시 Finding, 외부 공급자 오류 본문은 전송하지 않는다. 응답은 서버가 정해 둔 항목 수·길이·필드 형식을 검증하고 일반 안내로만 표시한다. AI 결과로 노출·유효성·심각도를 판정하거나 외부 키를 변경하거나 대응 건 상태를 자동 전환하지 않는다.

초기 실험은 합성 표본에 한정한다. 실제 운영 호출을 켜기 전에는 [Groq 데이터 제어](https://console.groq.com/docs/your-data)와 보관 설정을 확인하고 조직의 외부 전송 승인을 받는다. 무료 한도 초과나 공급자 장애는 기본 가이드로 처리한다.

## 검증

전송 본문과 일반 로그에 제외 필드가 없는지 시험한다. 공급자 무응답·429·잘못된 JSON·과도한 길이에서도 기본 가이드가 반환되고, 대응 건 상태와 조치 기록이 바뀌지 않아야 한다. API 키나 외부 서비스가 없는 개발 환경에서도 같은 기본 가이드 계약을 확인한다.
