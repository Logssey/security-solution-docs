# ADR-S009 — 기본 대응 가이드와 선택형 AI

- 상태: **Accepted**
- 결정일: 2026-10-19
- 기준: [외부 조치 경계](ADR-S004.md), [원문 미보관](ADR-S005.md), [대응 정책](../../02-functional-design/response-policy.md)

## 배경

유형별 조치 순서는 AI·외부 서비스가 없어도 제공해야 한다. 공급자 장애·한도·응답 오류가 담당자 지정·외부 조치 기록·재검사·해결을 막아서는 안 된다.

## 결정

버전이 고정된 기본 대응 가이드를 제공한다. 선택형 AI는 발급자·키 유형·구성·유효성·대응 단계에 맞는 점검 항목과 순서를 선택한다. 서버는 등록된 절차 코드를 검증한 후 한국어 안내로 변환한다. 공급자는 서버 설정으로 한 곳을 선택하며 기본 선택은 Claude Sonnet 5.5다. GroqCloud의 openai/gpt-oss-20b도 별도 선택으로 지원한다. 공급자별 활성화와 서버 인증 설정을 확인하고 사용자가 가이드 생성을 요청할 때 호출한다.

Claude 가이드는 AWS·GitHub·Notion의 현재 대응 건에서 모든 관련 위치의 열람 권한과 서버 사용 설정을 확인한다. 출처 분류와 합성 표본 여부는 Claude의 다섯 enum 요청을 차단하는 조건으로 사용하지 않는다. Groq의 기존 합성 TEST 제한은 해당 어댑터의 호환 정책으로 유지한다. 캐시를 사용할 때도 현재 권한과 건 상태를 다시 확인한다.

외부 입력에는 서버 허용 목록의 발급자·키 유형·구성·검증·대응 단계 등 **제한된 enum만** 담는다. 원문·마스킹 끝자리·지문·저장소·계정·경로·원천 참조·자유 메모·도구 Finding·외부 오류 본문은 전송하지 않는다. 응답 항목 수·길이·필드를 서버가 검증하고 일반 안내로만 표시한다.

AI는 노출·유효성·심각도·건 상태를 판정하지 않으며 외부 키 변경 명령을 생성·실행하지 않는다. 비활성·키 없음·무응답·429·잘못된 JSON·길이 초과에는 기본 가이드로 반환하고 대응 명령·조치 기록을 그대로 처리한다.

## 근거와 결과

공급자와 화면 응답 계약을 분리해 Claude 등 승인된 다른 공급자로 교체해도 업무 규칙을 바꾸지 않는다. 공급자 활성화·변경 시 외부 전송 범위·보관 설정·비용·한도를 검토하고 합성 표본으로 검증한다. 제외 필드가 요청·로그에 들어가지 않고 AI 결과가 판정·상태를 바꾸지 않는지 검사한다.

API 키는 서버 환경변수 또는 보호된 파일 참조로 제공한다. 브라우저에는 공급자·모델·생성 시각·캐시 여부와 안전한 사유 코드만 반환한다. 인증·접근 권한·결제·한도·시간 초과·응답 거부를 구분하고 기본 가이드를 함께 제공한다. 호출량은 배포 전체 DB 원장으로 합산한다.

Claude Messages API와 구조화 출력 규격을 사용한다. [Claude API](https://platform.claude.com/docs/en/api/overview), [구조화 출력](https://platform.claude.com/docs/en/build-with-claude/structured-outputs), [모델](https://platform.claude.com/docs/en/models/overview)

## 별도 조사 요약과의 경계

대응 가이드는 다섯 enum으로 점검 절차를 구성한다. 근거를 정리하는 별도 risk-briefing은 전용 사실·권한·전송 정책을 적용한다. 두 기능과 모든 replica의 외부 호출 예산은 같은 DB 원장을 사용한다. [ADR-S011](ADR-S011.md), [AI 조사 요약 계약](../risk-briefing-contract.md)
