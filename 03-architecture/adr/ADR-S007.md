# ADR-S007 — 위험 등급과 기존 통합 점수

- 상태: **Accepted — 4등급, 미평가와 초기 산정 정책**
- 결정일: 2026-10-09
- 기준: [PRD v0.3](../../01-requirements/PRD.md), FR-07, FR-10, FR-11, NFR-05

## 이슈

자격 증명의 유효성, 노출과 영향 범위는 하나의 숫자 점수로 충분히 설명되지 않는다. 등급은 확인된 근거를 바탕으로 산정하고 확인되지 않은 정보는 별도로 표시해야 한다.

## 최종 결정

통합 대시보드와 시크릿 기능은 숫자 점수 대신 **CRITICAL/HIGH/MEDIUM/LOW 네 등급**의 분포와 건수, 판정 근거를 제공한다. 유효성, 검토 여부, 조치 상태와 심각도를 혼합하지 않는다. 근거가 부족하면 임의 LOW로 넣지 않고 미평가를 표현한다.

## 산정과 전환

노출 범위, 확인된 권한, 환경, 데이터 영향과 악용 근거를 [심각도 판정 정책](../../02-functional-design/severity-policy.md)의 입력으로 사용한다. 정책 버전과 증거를 기록하고 근거 부족은 미평가로 둔다. [등급 조사](../../05-research/verification-and-risk.md)는 근거 자료이며 이 정책을 외부 표준의 공식 산식으로 취급하지 않는다.

기존 100점 UI와 API의 점수 필드는 전환 대상이다. 현재 대응 건의 대표 등급은 미해결 노출 위치의 가장 높은 확인 등급으로 표시하고 미평가 위치 수를 병기한다. 전체 제품의 대표 등급은 임의로 만들지 않는다. 기존 점수 필드의 사용처와 호환 기간은 실제 코드 확인 후 전환한다. 예외 승인으로 자격 증명의 유효성이나 영향 근거를 삭제하지 않는다.

## 검증

같은 근거에 같은 등급이 나오는 정책 버전과 테스트 사례를 마련한다. 무효 판정만으로 과거 사고 심각도, 이력을 삭제하지 않는다. 확인 불가와 미평가를 숨기지 않는다.
