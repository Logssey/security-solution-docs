# ADR-S001 — 룰 기반 탐지와 키 유형 지원 범위

- 상태: **Accepted — Gitleaks를 초기 탐지 엔진으로 사용**
- 결정일: 2026-10-09
- 기준: [PRD v0.3](../../01-requirements/PRD.md), FR-01부터 FR-04, NFR-04

## 이슈

AWS, GitHub, Notion, K8s에 연결된 코드, CI/CD 설정, 문서, 클라우드 자원에는 정형 토큰뿐 아니라 키 쌍, 개인키, 암호, 연결 문자열이 존재할 수 있다. 발견 위치와 발급자가 다를 수 있어 단순 접두사만으로 모든 유형을 판정할 수 없다.

여기서 정적 탐지는 코드의 전체 실행 경로나 취약점을 분석하는 일반 SAST가 아니라 읽은 콘텐츠에서 자격 증명 후보를 찾는 비밀 탐지다. 후보 발견과 실제 유효성, 사용 여부, 영향 평가는 서로 다른 단계다.

## 최종 결정

초기 탐지 엔진은 **Gitleaks CLI** 하나로 정한다. AI를 탐지에 사용하지 않는다. 모든 연결의 텍스트는 수집 어댑터가 승인된 원천 객체, 버전과 위치를 추적하면서 `stdin` 모드로 전달한다. GitHub의 승인된 브랜치와 커밋 이력은 수집기가 파일 버전 또는 변경 내용을 읽어 각 검사 단위로 전달한다. 수집 실패, API가 반환하지 않은 이력과 크기 제한으로 건너뛴 콘텐츠는 누락 범위로 기록한다. 초기 구조에서 수집원이 Gitleaks에 직접 로그인하게 하거나 Git 저장소를 워커 디스크에 복제하지 않는다.

기본 Gitleaks 룰을 출발점으로 사용하고 부족한 유형은 버전 관리되는 TOML 설정의 형식, 접두사, 정규식, 문맥 룰로 확장한다. 룰 ID, 설정 해시, Gitleaks 실행 파일 버전과 원천 위치를 ScanRun 및 Finding에 기록한다. 룰 추가와 허용 목록 변경은 합성 정상 및 노출 표본의 회귀 시험을 통과한 뒤 배포한다. 키 ID나 공개 인증서처럼 단독 비밀이 아닌 구성요소는 별도로 분류하고, 불완전 key set을 유효한 전체 키로 표시하지 않는다.

Gitleaks는 **후보 탐지만** 수행한다. 원문을 포함할 수 있는 입력과 결과는 제한된 워커 안의 프로세스 파이프로 주고받고 일반 파일, 보고서, 로그에 쓰지 않는다. 워커는 결과를 메모리에서 원천 위치에 연결하고 정규화, 동일성 판정 및 비밀 제거한 뒤 메타데이터만 저장한다. 구조화 결과를 원문 없는 영속 기록으로 변환할 수 없거나 파이프 실행이 검증되지 않으면 해당 범위의 스캔을 실패로 기록한다. 스캐너 종료 코드만으로 0건 성공을 판정하지 않고 결과 파싱과 실행 오류를 구분한다. 별도 공급자 검증기는 [ADR-S002](ADR-S002.md)를 따른다.

## 검토한 대안

TruffleHog는 다양한 소스와 탐지기를 제공하지만 기본 제공 검증 결과를 이 제품의 승인된 유형별 검증 계약으로 그대로 사용할 수 없다. 초기 실행에는 결합하지 않고, Gitleaks의 측정된 유형별 누락을 해결할 필요가 있을 때 독립 평가셋으로 비교한다. 자체 정규식 엔진을 처음부터 작성하는 방식은 초기 룰 관리와 품질 검증 부담이 커서 채택하지 않는다. Gitleaks의 상위 프로젝트는 기능 추가를 중단하고 보안 패치에 집중한다고 안내하므로, 새 유형은 버전 관리 룰로 보완하고 지원 한계를 계속 측정한다.

## 영향, 검증

- 탐지와 유효성 검사를 별도 단계로 분리한다. 탐지 결과 자체를 VALID 또는 INVALID로 변환하지 않는다.
- 유형별 정상, 오탐, 변형, 누락 구성요소 사례로 재현율과 오탐률을 측정한다.
- 배포 전 정확한 Gitleaks 실행 파일 버전과 해시를 고정한다. 도구명, 버전, 룰 ID와 설정 해시를 저장하고 CI/CD 설정을 포함한 위치별 지원 여부와 수집 누락을 보고한다.
- 동일 키의 여러 위치와 엔진 결과를 연결하되 근거 없이 서로 다른 값들을 한 key set으로 묶지 않는다.
- `stdin`에서 원본 파일 경로를 직접 보지 못하는 룰과 Git 이력 API의 크기 제한을 별도 평가한다. 경로 문맥이 필요한 룰의 누락이 발견되면 해당 유형을 지원 완료로 표시하지 않고 수집 및 스캔 방식을 다시 결정한다.
