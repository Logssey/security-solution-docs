# 심각도 판정 정책

기준: [PRD](../01-requirements/PRD.md) FR-07, FR-10, [ADR-S007](../03-architecture/adr/ADR-S007.md). 이 정책은 프로젝트의 초기 판정 규칙이며 외부 표준의 공식 산식이 아니다. 정책 버전은 `severity-v1`로 기록한다.

## 1. 입력과 판정 순서

평가 입력은 비정상 노출 위치와 공개 범위, 발급 주체, 확인된 권한과 자원, 운영 환경, 지원되는 사용 증거, 악용 증거 및 각각의 확인 시각이다. 유효성 상태와 심각도는 독립적으로 보존한다. 미지원 API, 권한 부족이나 검사 실패로 근거가 없으면 낮은 영향으로 간주하지 않는다.

확인된 근거가 여러 등급에 해당하면 더 높은 등급을 사용한다. 심각도를 낮추려면 이전 높은 등급의 근거가 더 이상 적용되지 않는다는 새 증거와 판정자를 기록해야 한다. 검사 오류, 예외 승인, 체크리스트 완료는 등급을 자동으로 낮추지 않는다.

| 판정 | 필요한 근거 |
|---|---|
| CRITICAL | 공개 또는 광범위한 비정상 노출과 확인된 운영 관리자 수준의 권한이 함께 있거나, 중대한 악용 사실이 독립 증거로 확인됨 |
| HIGH | 비정상 노출과 중요 운영 자원 또는 민감 데이터에 영향을 줄 수 있는 확인된 권한이 있음. CRITICAL 조건에는 해당하지 않음 |
| MEDIUM | 비정상 노출이 확인되고 권한과 대상이 제한됨을 확인했으나 대응이 필요한 영향이 남음 |
| LOW | 제한된 비운영 자원과 좁은 권한, 낮은 노출 범위가 긍정적 근거로 확인됨 |
| 미평가 | 판정에 필요한 노출, 권한 또는 대상 근거가 부족하거나 상충함. 별도 검토 사유를 기록 |

VALID만으로 HIGH나 CRITICAL을 부여하지 않는다. UNKNOWN이어도 이전에 확인한 권한, 공개 노출이나 악용 근거는 유지한다. INVALID는 현재 인증 가능성에 대한 판정이며 과거 사고의 심각도나 영향 이력을 삭제하지 않는다. 정상 비밀 저장소에서 값이 발견된 사실만으로 비정상 노출이나 위험 등급을 만들지 않는다.

## 2. 위치와 대응 건의 표시

같은 키가 여러 위치에서 발견되면 각 비정상 노출 위치에 근거와 등급을 기록한다. 현재 대응 건의 대표 심각도는 미해결 비정상 노출 위치 중 확인된 가장 높은 등급이다. 미평가 위치가 함께 있으면 대표 등급 옆에 미평가 위치 수를 별도로 표시한다. 모든 미해결 위치가 미평가면 대표 심각도도 미평가다. 해결된 위치의 과거 높은 등급은 이력에 보존하며 현재 대표 등급을 자동으로 결정하지 않는다.

평가에는 정책 버전, 판정자 또는 자동 규칙 ID, 사용한 증거 ID, 각 증거의 확인 시각, 부족한 정보와 평가 시각을 남긴다. 등급 분포와 매트릭스는 [대응 정책](response-policy.md)의 현재 대응 건 범위를 사용한다.

## 3. 확인 사례

| 사례 | 기대 결과 |
|---|---|
| 유효한 키지만 발견 위치가 승인된 비밀 저장소뿐임 | 인벤토리로 유지, 비정상 노출 등급 없음 |
| 공개 위치와 운영 관리자 권한이 확인됨 | CRITICAL 및 근거 표시 |
| 비정상 노출은 확인됐지만 권한과 대상 조회가 불가능함 | 미평가 및 수동 검토 |
| LOW 근거가 있었으나 공급자 검사에 실패함 | 실패를 UNKNOWN으로 기록, 검증 실패만으로 등급 변경 없음 |
| 한 위치가 해결됐고 다른 공개 위치가 남음 | 남은 위치 기준으로 대표 등급 유지, 대응 건 자동 해결 금지 |

실제 공급자별 권한 의미와 정책 적용 결과는 합성 사례와 승인된 테스트 계정으로 확인한다.
